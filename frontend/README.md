# EchoRoom — Frontend Client

The web client for **EchoRoom – Anonymous Thoughts & Empathy Platform**, built with React 19, Vite, Tailwind CSS, Lucide icons, Recharts, and Socket.IO Client.

## Features
- **Responsive Layout**: Desktop sidebar navigation, mobile drawer backdrop, and bottom navigation bar.
- **Calm Midnight Theme**: Human-designed palette featuring midnight charcoal (`#0d0f14`), subtle surfaces (`#161922`), elevated cards (`#1b1f2b`), and calming lavender accents (`#b4a0e5`).
- **Real-Time WebSockets**: Live presence tracking and instantaneous chat inside ephemeral discussion rooms.
- **Serendipitous Discovery**: Random unread thought explorer with animated reveals.
- **Interactive Empathy Reactions**: Live atomic reaction buttons and counters.
- **Community Analytics**: Dynamic visualization of emotional trends and participation metrics.

## Development Scripts
- `npm run dev` — Starts local Vite development server on `http://localhost:5173`.
- `npm run build` — Compiles production-ready bundle into `dist/`.
- `npm test` — Executes automated unit tests with Node test runner.
- `npm run preview` — Serves local production build preview.
